# FontRenderer

This project is a self made library useful to draw text on an openGL contexte.

The project use the library freeType for the parsing of the TTF file (the goal is to use a self made parser later auTTFparser). It use true type glyph and not bitmap. The triangulation algorithme is ear clipping.
